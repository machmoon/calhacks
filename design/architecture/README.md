# Architecture diagram

`output/wright-architecture-stack.png` is the 3200 × 1800 (16:9) diagram.
`output/wright-architecture-stack.svg` is the editable vector source.

`render-stack.mjs` regenerates both using Node.js and `sharp` (available through
normal Node module resolution or `NODE_PATH`). The diagram distinguishes current
storage from PCB generation integration that remains in progress.
